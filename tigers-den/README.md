# How to Run the App

1.  **Open Terminal**
    -   Press `Command + Space`
    -   Type `Terminal` and hit Enter.

2.  **Go to the App Folder**
    -   Copy this line, paste it into Terminal, and hit Enter:
        ```bash
        cd "/Users/28vsagar/Downloads/APP prototype capstone/tigers-den"
        ```

3.  **Install Dependencies**
    -   Copy this line, paste it, and hit Enter:
        ```bash
        npm install
        ```
    -   *If it says "command not found", you need to install Node.js from [nodejs.org](https://nodejs.org/).*

4.  **Start the App**
    -   Copy this line, paste it, and hit Enter:
        ```bash
        npx expo start
        ```

5.  **View the App**
    -   Press `w` to open in your browser.
    -   Or scan the QR code with your phone (requires "Expo Go" app).
